# ChatSpace для CharmDate (Qpid Network Agency System)

Специализированная агентская платформа для сайта **CharmDate** (`charmingdate.com/lady`) — полный функциональный аналог **Chatspace / TopChat**, решающий две ключевые задачи:
1. **Безопасность и Zero-Setup**: Операторы работают в едином мультичате и **не знают паролей** от анкет девушек на CharmDate.
2. **Автоматизация**: Авто-инвайтер в Live Chat, контроль суточного лимита Admirer Mail (до 50 писем на анкету), цепочка First EMF (с интервалом 6+ часов) и быстрое решение капчи.

---

## 🏗 Архитектура

- **`backend/`**: Центральный сервер (Node.js, Express, WebSocket, встроенный SQLite `node:sqlite`, шифрование паролей AES-256-GCM, сервис автоперевода RU ↔ EN).
- **`frontend/`**: Веб-приложение (React 19, Tailwind CSS, Lucide Icons) — включает **Панель Овнера** (Admin Panel) и **Мультичат Оператора** (Multi-Chat Workstation).
- **`extension/`**: Chrome Extension (Manifest V3) — браузерный мост, авторизующийся на `charmingdate.com/lady` без раскрытия паролей оператору, перехватывающий сообщения и капчи.

## 🚀 Быстрый запуск

### 1. Запуск сервера и интерфейса
В папке `chatspace`:
```bash
cd backend
npm start
```
Сервер запустится на **`http://localhost:3001`**, где сразу доступен и веб-интерфейс, и API.

### 2. Подключение расширения Chrome
1. Откройте Google Chrome и перейдите по адресу: `chrome://extensions/`.
2. В правом верхнем углу включите **«Режим разработчика»** (Developer mode).
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку:
   `/Users/artemrudenko/Desktop/chatspace/extension`
4. В иконке расширения введите токен оператора (или он подтянется автоматически при входе в веб-панель).

## 📋 Основной функционал

### 1. Панель Овнера (Admin Panel)
- **Добавление анкет девушек**: ID в CharmDate (`C...` или `P...`), пароль от `charmingdate.com/lady` (шифруется AES-256), индивидуальный прокси, аватар.
- **Управление сотрудниками**: создание логинов и паролей операторов.
- **Распределение смен (Division of Work)**: закрепление анкеты за оператором в 1 клик с указанием времени смены (например, 08:00 - 20:00).
- **Живой эфир чатов**: сквозной мониторинг всех диалогов агентства в реальном времени.

### 2. Рабочее место Оператора (Unified Multi-Chat)
- **Все чаты в одном окне**: входящие сообщения со всех назначенных девушек попадают в единый список.
- **Двусторонний автоперевод**:
  - Входящие сообщения от мужчин на английском мгновенно переводятся на русский.
  - Оператор пишет по-русски — система на лету переводит и по нажатию `Enter` отправляет качественный английский текст.
- **Мини-CRM мужчины**: карточка клиента с возрастом, страной, историей переписки и заметками оператора.
- **Быстрые фразы**: заготовки ответов и шаблоны в один клик.

### 3. Автоматизация писем (Mail Center)
- **Admirer Mail**:
  - Строгий учет суточного лимита CharmDate (**50 писем в 24 часа** на анкету) с визуальным прогресс-баром.
  - Поддержка шаблонов **Категории A** (письма до 6000 знаков) и **Категории B** (виртуальные открытки 50–150 знаков).
- **First EMF**:
  - Список мужчин после завершения первого чата.
  - Автоматический контроль кулдауна: не менее 6 часов между письмами (до 5 повторных).
- **Модальное окно капчи**:
  - При появлении защитного 4-значного кода на сайте CharmDate оператор видит всплывающее окно и вводит код за 2 секунды.
